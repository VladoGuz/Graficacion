# Visualizador de Gráfico de Barras 3D - MVC + ESM

Este proyecto es un visualizador interactivo de gráficos de barras horizontales en 3D




## Instrucciones para Ejecutar el Proyecto

### 1. Compilar el Código TypeScript
Para compilar los archivos fuente `.ts` ubicados en `/src` al directorio `/dist`:
```bash
npx tsc
```
Si deseas realizar cambios y que estos se compilen automáticamente en tiempo real en segundo plano:
```bash
npx tsc -w
```

### 2. Iniciar el Servidor de Desarrollo


Para ejecutarlo de forma segura a través de un servidor HTTP local y abrir automáticamente tu navegador web:
```bash
npm run dev
```
